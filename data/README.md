# Data files

`raw_dvcs_xsec_diff.csv` is a renamed copy of the uploaded
`data(20260807-003945).csv`. It is included so the preparation and training
workflow can be reproduced without an external download.

The clean common-support table and full cleaning audit are in the top-level
`dvcs_xsec_diff_prepared/` directory. Rerunning the preparation script may
replace those files if cleaning options are changed.
